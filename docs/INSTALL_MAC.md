# Install ReliefForge 1.0.0

Requires an Apple Silicon Mac running macOS 26 or later. Intel Macs and older macOS versions are not supported by this binary build.

1. Open the DMG and drag ReliefForge.app to the Applications shortcut.
2. Open ReliefForge from Applications.
3. Topographic Waves opens automatically. Try the Examples library's 12 built-in maps, or open your own image. All features and exports are free; creator-support links are optional.

No Homebrew or separate Qt/Open CASCADE installation is needed.

This community build is ad-hoc signed, not Developer ID signed or Apple-notarized. If macOS blocks it, verify that you trust the download and consult [Apple's per-app opening instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/26/mac/26). Do not disable system-wide security protections.
